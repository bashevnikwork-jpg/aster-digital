# Редагування сайту через Google Drive

Весь текстовий контент сайту SkyBreeze живе в **одній Google Таблиці** на Google Drive.
Раз на день робот на GitHub сам зчитує цю таблицю, пересобирає сайт і публікує зміни —
**торкатися коду не треба**.

```
Google Таблиця (на Drive)  ──►  sync_drive.py  ──►  content/*.json  ──►  build  ──►  сайт
        ▲                          (GitHub Actions, раз на день або вручну)
   ви редагуєте тут
```

Синхронізація тільки **читає** таблицю і **зливає, а не замінює**: порожня клітинка/рядок/вкладка
залишає те, що вже опубліковано. Недозаповнена таблиця не зможе «стерти» сайт.

---

## Частина 1. Налаштування — 3 кроки, без Google Cloud

> Ніяких сервісних акаунтів, ключів і секретів. Таблиця просто відкрита «на перегляд за
> посиланням», і робот читає її через звичайний публічний CSV-експорт. Контент таблиці і так
> публічний (він на сайті), тому це безпечно.

### Крок 1. Створити Google Таблицю з готовим контентом

У репозиторії вже є CSV-шаблони з **поточним** текстом сайту: `content/sheet-template/`.

1. Створіть нову Google Таблицю в [цій папці Drive](https://drive.google.com/drive/folders/12bEHzBVwA2vTzIVmVDsoPmXvY1UWn_jb).
   Назвіть її **SkyBreeze Content**.
2. Для кожного `*.csv`: **Файл → Імпорт → Завантажити** → оберіть CSV →
   **«Вставити новий аркуш»** → Імпортувати. Назвіть аркуш як файл (без `.csv`).
   Потрібні вкладки: `Settings`, `Texts`, `Services`, `Pricing`, `Portfolio`, `FAQ`,
   `Process`, `Advantages`, `Mission`, `After`.
3. Видаліть порожній «Аркуш1».

### Крок 2. Відкрити доступ «за посиланням»

Правий верхній кут → **Надати доступ (Share)** → у розділі «Загальний доступ»
оберіть **«Усі, хто має посилання» → Переглядач (Viewer)** → Готово.

### Крок 3. Дати ID таблиці

В URL таблиці: `docs.google.com/spreadsheets/d/`**`ЦЕЙ_ID`**`/edit` — скопіюйте `ЦЕЙ_ID`
і вставте його останнім рядком у файл `content/_sheet_id.txt` (замість коментарів).
Можна просто надіслати ID розробнику — він впише і закомітить.

**Готово.** Далі сайт синхронізується сам.

## Частина 2. Як редагувати контент щодня

1. Відкрийте Google Таблицю **SkyBreeze Content**.
2. Змініть текст у потрібній клітинці (довідник вкладок нижче).
3. Зміни зʼявляться на сайті:
   - **автоматично** — раз на день (близько 08:00 за Києвом), або
   - **одразу** — GitHub → вкладка **Actions** → зліва **«Sync content from Google Drive»**
     → **Run workflow**. Через 1–2 хвилини сайт оновиться.

### Довідник вкладок

| Вкладка       | Що контролює                                                          |
|---------------|-----------------------------------------------------------------------|
| **Settings**  | Телефон, email, Telegram, верхня плашка, футер, підписи CTA            |
| **Texts**     | Усі заголовки та описи секцій (hero, процес, місія, послуги, FAQ…)     |
| **Services**  | 6 послуг: назва, ціна, опис, «що ви отримаєте», результат             |
| **Pricing**   | Пакети та ціни                                                        |
| **Portfolio** | Кейси портфоліо                                                       |
| **FAQ**       | Питання та відповіді                                                  |
| **Process**   | Кроки процесу (Аналіз → Сайт → Реклама → Оптимізація)                 |
| **Advantages**| Блок «Чому саме ми»                                                   |
| **Mission**   | Три опори секції «Наша місія»                                         |
| **After**     | Кроки «Що відбувається після заявки»                                  |

Правила:
- У **Settings** і **Texts** редагуйте **тільки колонку `value`**; колонку `key` не чіпайте.
- Список у клітинці (напр. «що ви отримаєте») — це **кілька рядків в одній клітинці**
  (`Alt+Enter` / `Option+Enter`).
- Можна виділяти слово жирним через `<strong>...</strong>`.
- Додати послугу/кейс/питання — новий рядок; прибрати — видалити рядок.

### Чого таблиця поки не змінює
- **Зображення/відео портфоліо** — лежать у репозиторії (`public/assets/…`). Оновити картинку —
  покласти файл із тією ж назвою (або надіслати розробнику).
- **Технології** і складні motion-блоки — рідко змінюються (`content/stack.json`, `content/motion.json`).

## Для розробника

- Оновити CSV-шаблони після зміни структури: `python export_sheet_template.py`.
- Перевірити синхронізацію локально: `python sync_drive.py --check` (нічого не пише).
- Повний ланцюжок робота: `sync_drive.py` → `parts.py` → `build.py`.
- ID таблиці: `content/_sheet_id.txt` (або env `SKYBREEZE_SHEET_ID`). Розклад: `.github/workflows/sync-content.yml`.
