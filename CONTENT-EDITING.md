# Редагування сайту через Google Drive

Весь текстовий контент сайту SkyBreeze живе в **одній Google Таблиці** на Google Drive.
Раз на день робот на GitHub сам зчитує цю таблицю, пересобирає сайт і публікує зміни —
**торкатися коду не треба**.

```
Google Таблиця (на Drive)  ──►  sync_drive.py  ──►  content/*.json  ──►  build  ──►  сайт
        ▲                          (GitHub Actions, раз на день або вручну)
   ви редагуєте тут
```

Принципи безпеки, закладені в синхронізацію:
- Робот **тільки читає** таблицю, ніколи в неї не пише.
- Синхронізація **зливає, а не замінює**: якщо клітинка/рядок/вкладка порожні або відсутні —
  залишається те, що вже опубліковано. Недозаповнена таблиця не зможе «стерти» сайт.

## Частина 1. Одноразове налаштування (≈ 20 хвилин)

Це треба зробити один раз. Далі — тільки редагувати таблицю.

### Крок 1. Створити Google Таблицю з готовим контентом

У репозиторії вже є готові CSV-шаблони з **поточним** текстом сайту:
`content/sheet-template/` (Settings, Texts, Services, Pricing, Portfolio, FAQ,
Process, Advantages, Mission, After).

1. Створіть нову Google Таблицю в тій самій папці Drive
   (`https://drive.google.com/drive/folders/12bEHzBVwA2vTzIVmVDsoPmXvY1UWn_jb`).
   Назвіть її, наприклад, **SkyBreeze Content**.
2. Для кожного файлу `*.csv`: **Файл → Імпорт → Завантажити** → оберіть CSV →
   **Місце імпорту: «Вставити новий аркуш»** → Імпортувати.
   Перейменуйте аркуш так само, як файл (без `.csv`): `Settings`, `Texts`, `Services` тощо.
3. Видаліть порожній аркуш «Аркуш1», який був створений за замовчуванням.

> Назви вкладок мають збігатися: `Settings`, `Texts`, `Services`, `Pricing`,
> `Portfolio`, `FAQ`, `Process`, `Advantages`, `Mission`, `After`.

### Крок 2. Скопіювати ID таблиці

Відкрийте таблицю і подивіться на URL:
`https://docs.google.com/spreadsheets/d/`**`ЦЕЙ_ДОВГИЙ_РЯДОК`**`/edit`
Скопіюйте `ЦЕЙ_ДОВГИЙ_РЯДОК` — це `SKYBREEZE_SHEET_ID`.

### Крок 3. Створити сервісний акаунт Google (доступ для робота)

Робот заходить у таблицю не під вашим паролем, а під окремим «технічним» акаунтом.

1. Відкрийте <https://console.cloud.google.com/> (увійдіть як `oleksandrbasevnik@gmail.com`).
2. Вгорі створіть новий проєкт, напр. **skybreeze-sync** (або оберіть будь-який наявний).
3. Увімкніть **Google Sheets API**:
   APIs & Services → Library → знайдіть «Google Sheets API» → **Enable**.
4. Створіть сервісний акаунт:
   APIs & Services → Credentials → **Create credentials → Service account**.
   Ім'я — `skybreeze-sync`, решту пропустіть, **Done**.
5. Відкрийте створений сервісний акаунт → вкладка **Keys** →
   **Add key → Create new key → JSON → Create**. Завантажиться файл `*.json` — це ключ.
   Всередині є рядок `"client_email": "skybreeze-sync@...gserviceaccount.com"` — скопіюйте цей email.

### Крок 4. Дати роботу доступ до таблиці

Відкрийте вашу Google Таблицю → **Надати доступ (Share)** → вставте email сервісного
акаунта (`...gserviceaccount.com`) → роль **Читач (Viewer)** → Надіслати.

### Крок 5. Додати два секрети в GitHub

У репозиторії `bashevnikwork-jpg/aster-digital`:
**Settings → Secrets and variables → Actions → New repository secret.**
Додайте два секрети:

| Назва секрету                  | Значення                                                        |
|--------------------------------|-----------------------------------------------------------------|
| `SKYBREEZE_SHEET_ID`           | ID таблиці з Кроку 2                                             |
| `GOOGLE_SERVICE_ACCOUNT_JSON`  | **весь вміст** JSON-файлу-ключа з Кроку 3 (відкрийте, скопіюйте все) |

Готово. З цього моменту сайт синхронізується автоматично.

## Частина 2. Як редагувати контент щодня

1. Відкрийте Google Таблицю **SkyBreeze Content**.
2. Змініть текст у потрібній клітинці (див. довідник вкладок нижче).
3. Збережеться автоматично. Зміни зʼявляться на сайті:
   - **автоматично** — раз на день (близько 08:00 за Києвом), або
   - **одразу** — вручну: GitHub → вкладка **Actions** → зліва
     **«Sync content from Google Drive»** → **Run workflow**. Через 1–2 хвилини сайт оновиться.

### Довідник вкладок

| Вкладка       | Що контролює                                                              |
|---------------|---------------------------------------------------------------------------|
| **Settings**  | Телефон, email, Telegram, текст верхньої плашки, футер, підписи CTA        |
| **Texts**     | Усі заголовки та описи секцій (hero, процес, місія, послуги, FAQ тощо)     |
| **Services**  | 6 послуг: назва, ціна, опис, «що ви отримаєте» (список), результат         |
| **Pricing**   | Пакети та ціни                                                            |
| **Portfolio** | Кейси портфоліо                                                           |
| **FAQ**       | Питання та відповіді                                                      |
| **Process**   | Кроки процесу (Аналіз → Сайт → Реклама → Оптимізація)                     |
| **Advantages**| Блок «Чому саме ми» (4 переваги)                                          |
| **Mission**   | Три опори секції «Наша місія»                                             |
| **After**     | Кроки «Що відбувається після заявки»                                      |

Правила заповнення:
- У вкладках **Settings** і **Texts** редагуйте **тільки колонку `value`**.
  Колонку `key` не чіпайте — це «адреса» тексту на сайті.
- Список у клітинці (напр. «що ви отримаєте», пункти пакета) — це **кілька рядків
  в одній клітинці**. Новий рядок усередині клітинки: `Alt+Enter` (Win) / `Option+Enter` (Mac).
- Можна використовувати `<strong>...</strong>`, щоб виділити слово жирним усередині абзацу.
- Щоб **додати** послугу/кейс/питання — додайте новий рядок у відповідну вкладку.
  Щоб **прибрати** — видаліть рядок.

### Чого таблиця поки не змінює
- **Зображення портфоліо** (скриншоти) і відео. Вони лежать у репозиторії
  (`public/assets/screenshots/`, `public/assets/motion/`). Щоб оновити картинку — надішліть її
  розробнику, або покладіть у репозиторій із тією ж назвою файлу.
- **Технології** (рухома стрічка логотипів) і складні motion-блоки — рідко змінюються,
  живуть у `content/stack.json` / `content/motion.json`.

## Для розробника

- Оновити CSV-шаблони після зміни структури контенту: `python export_sheet_template.py`.
- Перевірити синхронізацію локально (нічого не пише):
  `SKYBREEZE_SHEET_ID=... GOOGLE_SERVICE_ACCOUNT_JSON=... python sync_drive.py --check`.
- Повний ланцюжок, який виконує робот: `sync_drive.py` → `parts.py` → `build.py`.
- Розклад і кроки автоматизації: `.github/workflows/sync-content.yml`.
